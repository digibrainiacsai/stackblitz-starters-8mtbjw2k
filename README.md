# Fleet MVP (estático)

## Qué es
Dashboard super simple para validar interés:
- Sin backend.
- Lee `/public/data.json`.
- KPIs rápidos + costo por km por placa.

## Editar datos
1) Abre `public/data.json` en GitHub → Edit.
2) Cambia/añade filas (placa, periodo YYYY-MM, kms, costos).
3) Commit → Vercel redeploy → refresca.

## Desplegar
- Conecta el repo a Vercel → Deploy.
- Listo.
